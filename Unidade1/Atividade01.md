A solução para o problema seria o uso de várias máquinas;
A grande quantidade de dados requereria a divisão dos dados em blocos, por exemplo;
As maquinas fariam sozinhas o processamento de cada bloco de dados;
Um único computador teria o papel de receber os relatórios das outras máquinas e soma-los;
EXTRA. O computador cujo papel é juntar o resultado dos dados teria também a função
de identificar a falha e repassar os dados para outra máquina.
